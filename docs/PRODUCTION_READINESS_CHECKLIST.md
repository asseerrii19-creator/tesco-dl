# Production Readiness Checklist

- [ ] UAT business acceptance completed
- [ ] Real LMS connector tested against vendor sandbox
- [ ] LMS duplicate and failure recovery tested
- [ ] Corporate SSO/MFA decision implemented
- [ ] Final role and data-scope matrix approved
- [ ] HTTPS/domain/certificates configured
- [ ] Secrets moved to approved vault
- [ ] PostgreSQL backups and restore test completed
- [ ] Photo/file storage backup and restore test completed
- [ ] Monitoring, alerting and centralized logs enabled
- [ ] Security assessment and penetration test completed
- [ ] Data retention/privacy policy approved
- [ ] Client-facing status terminology approved
- [ ] Official report transfer/release workflow approved
- [ ] IEC/IEEE/client/manufacturer assessment profiles approved by Technical/Quality
- [ ] Offline device-management and remote-wipe policy approved
- [ ] Disaster recovery and support ownership assigned
