# Integrated Pilot Acceptance Criteria

1. Operations Manager can create a client sampling order linked to quotation/PO.
2. Sampling Supervisor can assign each item to a valid TSCO or client-side sampler.
3. Assigned sampler can open the task or use its assignment code.
4. The field record captures client, asset, serial, sampling point, package, GPS and photos.
5. A unique request number, barcode, QR and printable tag are generated.
6. Data Entry can Accept and Register, Return or Reject before physical receipt.
7. Return/rejection records preserve structured reasons and sampler linkage.
8. Successful Data Entry acceptance stores a LMS number and sets Awaiting Physical Receipt.
9. The accepted sample and package automatically appear in Full Laboratory Operations.
10. Receiving cannot complete physical receipt without an existing LMS number.
11. The barcode resolves the existing registered request and does not create a duplicate.
12. Laboratory results and status synchronize back to the main platform.
13. Technical Assessment reads current laboratory results and requires authorized reviewer action.
14. Report release synchronizes to the client dashboard/timeline.
15. Client users can access only their company's samples.
16. TSCO/client samplers cannot access unauthorized companies or assignments.
17. All material state changes create custody and/or audit records.
18. Management can view flow and Sample Man issue indicators.
