# GPS, Photos and Employee Data — Governance Principles

- Capture GPS only for the sample/asset location and chain-of-custody purpose.
- Display the purpose clearly to the Field Sample Man.
- Avoid continuous background employee location tracking.
- Store accuracy, timestamp and capture source with the coordinates.
- Allow an authorized correction workflow without silently overwriting original evidence.
- Restrict employee performance dashboards to authorized management roles.
- Preserve structured reasons for returns/rejections so metrics distinguish process issues from employee errors.
- Define retention periods for field photos, GPS and performance events before production rollout.
- Use metrics for coaching and improvement with human review.
