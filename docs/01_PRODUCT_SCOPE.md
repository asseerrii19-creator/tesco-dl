# Product Scope — v1.2 Integrated Pilot

## Product name

**TSCO Digital Laboratory Platform**

## Objective

Provide one traceable sample lifecycle from commercial request and field assignment through barcode collection, LMS registration, physical receipt, laboratory testing, technical review, report release and authenticated client visibility.

## Core actors

1. Operations Manager
2. Sampling Supervisor
3. TSCO Field Sampler
4. Client Sampler / Client Operations
5. Data Entry
6. Sample Receiving
7. Laboratory Technician / Chemist
8. Senior Chemist
9. Quality
10. Technical Manager
11. Management
12. Client User
13. System Administrator

## Integrated modules in this release

- Administration and master data
- Sampling orders and assignments
- Field Sampling
- Barcode / QR / tag
- GPS and photo evidence
- Data Entry validation
- LMS adapter and number linkage
- Physical Receiving / chain of custody
- Client Tracking Portal
- Full Laboratory Operations
- QC, calculations, reports and retained samples
- Controlled Methods / SOPs / EOPs
- Internal Technical Assessment
- Management and field performance indicators
- Audit records

## Pilot boundary

This release is suitable for internal controlled testing. The LMS adapter is mock and the technical assessment is a reviewer-support screen, not an autonomous final recommendation engine.
