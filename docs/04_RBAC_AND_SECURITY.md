# RBAC and Security Requirements

## Minimum production controls

- Corporate SSO / Microsoft Entra ID where available.
- Individual user accounts; no shared operational PIN.
- Role and site-scoped authorization enforced server-side.
- Client users restricted to their own organization and authorized projects/assets.
- Immutable audit events for sample identity, decisions, results and report release.
- File malware scanning and storage outside the database.
- Encryption in transit and at rest.
- Secrets stored in a vault, not source code.
- Development, test and production environments.
- Database backups, retention policy, disaster recovery and restore tests.
- Session expiry and multifactor authentication for privileged roles.
- Rate limiting, security logging and alerting.

## Field performance ethics

Sample Man metrics are evidence for coaching, workload planning and process improvement. A single automated score must not be used as the sole disciplinary or performance decision.
